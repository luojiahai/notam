Promotions have a tab of their own, beside Entries and Rules. It lists every promotion in the selected repository with the branch it was cut from, the pull request it opened, how many rules it carries, and the days it was created and last checked — filtered by open, merged or closed, and searchable by branch or pull request number. Refresh status sits in that toolbar, above the list it rewrites. Each repository in the sidebar counts the promotions open in it alongside its entries and drafts, and creating a rules pull request takes you straight to the tab it lands in.
